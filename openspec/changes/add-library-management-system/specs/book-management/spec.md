# Spec: Book Management

> 需求来自图书管理系统管理员图书信息增删改查。

## Requirements

### REQ-BM-001：图书字段建模
图书信息包含字段：书名（title）、作者（author）、ISBN、分类（category）、库存（stock）。
- 边界：ISBN 为唯一约束，重复新增/更新为冲突（409）。
- 库存语义：表示当前可借数量，>=0；借出扣减，归还恢复。

### REQ-BM-002：管理员图书增删改查
管理员可对图书执行新增、查询（分页）、更新、删除。
- 场景：新增图书 → 库存可初始化为任意 >=0；ISBN 重复返回 409。
- 场景：更新图书 → 可修改任意字段；若改 ISBN 为已存在值返回 409。
- 场景：删除图书 → 若存在未归还（status=ACTIVE/OVERDUE）借阅记录，禁止删除，返回 409。
- 权限：仅 ADMIN；非管理员访问返回 403。

### REQ-BM-003：库存非负
库存更新/恢复后不得为负；借阅扣减后若结果 <0 视为库存不足，返回 409。

## Out of Scope
- 图书副本物理条码与多副本建模。
- 分类层级树与分类管理后台。
